# Employee Management System

A Python-based Employee Management System that uses JSON for persistent data storage.

This project was built as a practical Python project to practice file handling, JSON, CRUD operations, loops, conditions, error handling, and problem-solving.

## Features

- Add new employees
- Automatically generate employee IDs
- List all employees
- Search employee by ID
- Update employee information
- Delete employees
- Delete confirmation using `y/n`
- JSON-based data persistence
- Basic input validation
- Menu-driven interface

## Technologies Used

- Python 3
- JSON
- File Handling
